## How to use
1. Pick the style the user names (or suggest 2-3 that fit their product and ask).
2. Read `design-md/<name>/DESIGN.md` from this skill's folder.
3. If the user wants it in the project, copy it to the project root as `DESIGN.md`.
4. Build/restyle the UI following its tokens and rules exactly. Combine with the `impeccable` skill when available.
5. Never reproduce logos, trademarks or brand names on the result — use the style, not the identity.

Update the library: `git -C <this skill dir> pull`.
